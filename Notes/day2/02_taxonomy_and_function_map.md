# Biomimicry Taxonomy → our functions (AskNature search paths)

Source: `Biomimicry Taxonomy.pdf` (Biomimicry Institute v6.1, CC BY-NC 4.0). The PDF is a
circular diagram, so the text extraction is unordered — the branches below are
reconstructed from it. **Check against the printed wheel before citing.**

The Taxonomy classifies biological strategies **by the function they serve**, and it is the
underlying structure of AskNature. Searching it by function is the mechanical version of
"biologize the question".

## Structure

`GROUP → SUB-GROUP → FUNCTION`, with these groups:

GET, STORE, OR DISTRIBUTE RESOURCES · MAKE · MODIFY · BREAK DOWN ·
PROCESS INFORMATION · MOVE OR STAY PUT · PROTECT FROM PHYSICAL HARM ·
MAINTAIN COMMUNITY

| Sub-group | Entries |

| **PROCESS SIGNALS** | Differentiate signal from noise · Transduce/convert signals · **Respond to signals** |

## Search paths for F0–F12

Use these as the literal navigation path in AskNature, and record which path produced which
model — that *is* the "research path" criterion 2 asks for.

| Our function | Taxonomy path | Biologized query |
|---|---|---|
| **F1** Reflect short-wave radiation | MODIFY → physical state → **light/color**; also PROTECT FROM NON-LIVING THREATS → **light** | How does nature reflect intense sunlight without pigment and without a mirror? |
| **F5** Shade a surface | PROTECT FROM NON-LIVING THREATS → **light**; MODIFY → **size/shape** | How does nature shade itself with its own geometry? |
| **F2** Emit long-wave radiation | TRANSFORM/CONVERT ENERGY → **thermal / radiant energy**; DISTRIBUTE → **energy** | How does nature dump heat to the night sky? |
| **F3** Transfer heat to air | DISTRIBUTE → **energy**; PROTECT FROM NON-LIVING THREATS → **temperature** | How does nature move heat into moving air? |
| **F4** Store thermal energy | **STORE → energy** | How does nature buffer a daily temperature extreme instead of resisting it? |
| **F6** Capture water | **CAPTURE, ABSORB, OR FILTER → liquids** (and gases, for humidity) | How does nature harvest water where there is no standing water? |
| **F7** Retain water | **STORE → liquids** | How does nature hold a reserve through a dry period? |
| **F8** Release water in a controlled way | **DISTRIBUTE → liquids**; MODIFY → **phase** | How does nature meter out evaporation so the reserve lasts? |
| **F9** Couple response to load | **SENSE SIGNALS → temperature** + **PROCESS SIGNALS → respond to signals**; REGULATE → **maintain homeostasis** | How does nature make a response stronger when the load is stronger, without a controller? |
| **F10** Keep a surface clean | PROTECT FROM NON-LIVING THREATS → **dirt/solids** | How does nature keep a functional surface clean without cleaning it? |
| **F11** Resist degradation | PREVENT STRUCTURAL FAILURE → **thermal shock, chemical/mechanical wear**; PROTECT → **light, ice** | How does nature survive UV, frost and driving rain for decades? |
| **F12** Attach to a substrate | **ATTACH → in/on solids, permanently** | How does nature attach to a rough vertical mineral surface? |

F9 is the one to notice: it does not sit in a single branch, it is the **pairing** of
*sense temperature* with *respond to signals*. That pairing is also how the Life's
Principles checklist phrases it — "the signal it sends, the antennae it uses to detect the
signal, and its response match".

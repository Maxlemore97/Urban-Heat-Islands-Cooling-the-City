# Image prompts — imagine.art

Twenty-nine self-contained prompts: twelve biological mechanisms, twelve of the same
strategies built into a street, and five for context and concepts. Each code block is
complete — subject, style and negative part are already in it, nothing to assemble. Copy the
whole block.

If imagine.art gives you a separate negative-prompt field, everything after
`Negative prompt:` goes there and the rest into the main field. If it does not, paste the
block as it is.

Numbering follows the slides in `../Output/Discovering_and_Abstracting.pptx`.

**Three rules before you start.** Never ask for text inside an image — generators garble
letters, and labels belong in Slides or LaTeX afterwards so they match our function IDs.
Never generate anything that looks like a measurement: a thermal-camera look with a colour
scale is fabricated data, not an illustration. And declare the tool in Appendix A, with
captions that say the figure is schematic.

Aspect ratio: **16:9** for full-width slide images, **4:3** for the column slot on the model
slides, **3:2** for report figures. Generate four variants and pick one.

## Where each one goes

| Image | Deck | Report |
|---|---|---|
| 01–12 | model slides 5–16, right-hand column | Section 3.1, one per model |
| 13 | title slide | Section 1.1, opening figure |
| 14–16 | concept slides after 19 | Section 3.2 |
| 17–28 | the same model slides, left column — biology on one side, the built version on the other | Section 3.1 abstraction table, third column: the technical interpretation |
| 29 | closing slide | Section 3.2 or Section 5 |

Pairing 01–12 with 17–28 on one slide is the strongest use of them: the organism on the left,
the same principle built on the right, and the abstraction band between the two. That is
exactly the three-column separation the lecture asks for — biological observation, abstracted
principle, possible technical interpretation — made visible in one glance.

The model slides have no image slot yet — the two text columns fill the width. Narrowing the
second column to make room for a 4:3 image is one number in `../Output/make_deck.py`.

**One caution for Section 3.2.** The rubric wants annotated concept drawings showing
components, flows, materials and key parameters. A generated image cannot do that — it has no
dimensions and no components it can name. Use 14–16 as the atmosphere and draw the annotated
version over the top. A generated picture presented as the engineering drawing would be
marked down.
